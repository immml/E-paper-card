# 墨礼（InkGift）· ESP32-S3 智能墨水屏贺卡

一张不用插电、写完就能送出去的电子贺卡。项目基于 ESP32-S3 与 3.7 英寸 240×416 黑白墨水屏，支持贺卡、名片、电子书、MP3、AI 听记和语音助手等形态。

## 项目状态

设计阶段。硬件设计文件、生产文件与项目文档正在整理中。

## 核心规格

- 主控：ESP32-S3-WROOM-1-N16R2
- 显示：3.7 英寸黑白墨水屏，240×416
- 电池：502080 锂聚合物电池，约 1000 mAh
- 框架：ESP-IDF
- 连接：Wi-Fi、BLE、NFC、microSD

详细设计、硬件选型、功耗分析和复刻注意事项见：[项目说明](文档/项目说明/OSH项目描述.md)。
