# 项目文件索引

## 按类别划分

### 软件

- [工具](../../软件/工具/)：项目辅助脚本，例如 netgrid.py。

### 硬件

- [设计文件](../../硬件/设计文件/)：原理图、PCB 网络表。
- [生产文件](../../硬件/生产文件/)：按生产批次归档的 Gerber、BOM、贴片坐标、ODB++ 等文件。

### 文档

- [项目说明](../项目说明/)：项目介绍与开源平台说明。
- [手册](../手册/)：元器件手册和显示屏手册。
- [工作记录](../工作记录/)：工作日志、提取资料和临时记录。
- 当前生产批次：2026-11-20。

## 命名规则

- 生产文件统一使用批次日期 YYYY-MM-DD。
- 元器件资料使用“型号_中文用途”命名。
- 设计输出使用“中文用途_日期”命名。
- 原始文件内容未修改，仅调整目录位置和文件名。
