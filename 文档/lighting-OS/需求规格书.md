## Kpower 与电量显示

去抖 20 ms，按稳定按下到稳定松开的时长分类：点按 `<200 ms`，短按 `200–1500 ms`（含端点），长按 `>2000 ms`，`(1500, 2000] ms` 无动作。下表按先后优先级处理关机事件。

| 状态 | 事件 | 行为 |
|---|---|---|
| 关机 | 按住期间检测到 USB 插入沿 | 锁存事件，在松开时优先请求 ROM 救援，不依赖按压档位。释放时仍须有 USB 才进入 USB 救援；已拔除则消费该手势，不启动。 |
| 关机 | 未按键时出现 USB 插入沿 | 自动正常开机；仅 USB 已在线不触发救援，也不反复开机。 |
| 关机 | 无上述插入沿 | 点按显示电量；长按松开正常启动（包括 USB 原本已在线）；其余不动作。 |
| 运行 | 点按 / 短按 / 长按 | 返回主界面 / 请求睡眠 / 松开后请求有序关机。 |
| 睡眠 | 长按 / USB 插入沿 | 长按松开唤醒 / 按配置唤醒；默认策略待定。 |

关机点按显示 3 s：`>50%` 两绿灯，`20–50%` 一绿灯，`<20%` 一红灯；充电中按对应档位以 1 Hz 闪烁。亮度初值约 10%，第三颗不用于电量档位。电源策略禁止启动时红灯快闪三次（电压阈值待实测，不等同于 20%）；测量无效不显示虚构百分比。WS2812 电气验收见硬件核实表。

## 实施边界

依次交付：需求核实 → 架构/API 与资源预算 → 最小硬件系统 → 核心服务 → 应用与媒体 → 云与安全 → 验收和发布。每阶段确认后再进入下一阶段，每个独立任务使用单独 Issue、分支和 PR。VRC522 从软件范围移除，不改原理图和 BOM；本阶段不烧录、不引入依赖、不发布。
