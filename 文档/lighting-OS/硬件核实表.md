# lighting OS 硬件核实表 v0.3

依据：2026-11-20 [BOM](../../硬件/生产文件/2026-11-20/BOM_主板_2026-11-20.csv)、[网表](../../硬件/设计文件/PCB数据/网络表_2026-11-20.enet)。原理图 [PDF](../../硬件/设计文件/原理图/原理图_2026-11-20.pdf) 是后续交叉复核依据。网表说明设计连接，不等于板级验证；本表无上电实测。

| 项 | 证据或决策 | 上板前检查 / 实测 |
|---|---|---|
| ESP32-S3 | BOM U2 为 N16R8，用户确认；旧 README 的 N16R2 不是本项目基线。 | 核对实物丝印、Flash/PSRAM 探测结果、绑带与金手指外部负载。 |
| PMIC 总线 A | U6 PC4/PC5 接 AXP2101 SDA/SCL；IRQ 只有测试点和上拉。 | CH32 轮询，不假定有 MCU 中断。核查寄存器、NTC、轮询负载及电源轨。 |
| 共享总线 B | ESP IO14/IO21、CH32 PC1/PC2、ES8311、SC7A20、金手指 p3/p4 共用。 | 核对 CH32 I²C 硬件实例和复用映射；验证另一总线的软件实现可行性、地址冲突、超时、掉电反灌。共享线路不是隔离边界。 |
| 救援 | CH32 PC3 经 Q3 对应 GPIO0；PD3 经 Q4 对应 EN；原生 USB 为 ESP IO19/20。 | 复核极性、上电顺序和绑带采样，验证 PVE 透传、重枚举及 ROM 下载恢复。P31 未识别，不作为接口定义。CH32 SWIO 网名对应 PD1，独立验证 WCH-LinkE。 |
| 电源与按钮 | ESP 3V3 对应 PMIC FB1；CH32 VDD 经 D12/D13 接 USB LDO 和电池；Kpower 接 PD4，K1～K4 对应 PD0/PA2/PA1/PD7。 | 实测完全关机与睡眠电流、低电低温启动、掉电时总线反灌、按键电压和功率轨依赖。不能仅凭网表认定关闭 DCDC1 足够。 |
| 电量 LED | PC7 `RGB` 驱动 LED4→LED3→LED2；TPS61023 的 VIN/EN 同名 `VSYS`，LED 供电为 5V。 | 核对实际 5V 轨能否在关机显示时供电、空闲电流和数据高电平裕量；覆盖电池/USB、温度和批次。未通过则暂停该功能并评审修改，不擅自改板。 |
| 音频 | BOM 含 ES8311、NS4150B、ZTS6216；ESP 网名为 IO3 MCLK、IO46 BCK、IO9 DI、IO10 WS、IO11 DO。 | 以原理图逐一复核串联器件和输入输出链路；确认绑带、功放差分与插座接法，不能假定支持普通耳机。 |
| 显示 | HINK-E037A03-A1 为主屏，24 针/240×416 作为待核对设计输入。卖家灰阶与买家评价不一致。 | UC8253 优先作为候选、UC8171 为备选；不是已识别控制器。核对 FPC 针脚、供电、BUSY 极性及波形来源后才上电。无可靠屏 ID 读取保证。首版以黑白、慢刷新设计，实测全刷耗时、残影、休眠恢复；不承诺快刷或灰阶。 |
| TF / 扩展 | TF 网名为 IO4 DAT0、IO5 CLK、IO6 CMD，按 1-bit SDMMC 验证。金手指出现 SPI、UART0 和绑带 IO45；p20 `CH32` 与 PC6 `CH32_1` 不相连，维持现状。 | 不假定支持安全热插拔或软件断开供电。PD2/p19 未分配用途。VRC522 不开发驱动；若仍贴装，验证不选通时总线释放，不能假定 SPI 已物理独占。 |
| 其他外设 | SC7A20 中断接 CH32；马达控制在 CH32 PC0；TPS7A02/TPS61023 属电源管理范围。 | 验证唤醒可用性、马达电流及 RF/音频干扰；未验证前不承诺抬手唤醒。 |

## 手册策略

厂商 PDF 不随本次提交发布。官方补齐目标：Espressif 的 ESP32-S3 Datasheet、Technical Reference Manual、WROOM-1/WROOM-1U Datasheet；WCH 的 CH32V003 Reference Manual（核对本地 CH32V003 PDF 类型）。本地已有 AXP2101、CH32V003、ES8311、NS4150B、SC7A20H、LED、TPS61023、TPS7A02 和 ZTS6216 文件，版本及适用性需核对。屏无原厂手册时先按上述验证门槛处理；MBR0530 结合实际器件料号及供电压降测试。
